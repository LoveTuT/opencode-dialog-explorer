# 前端设计与主题 Token

本文记录当前已实现的界面约定，供后续调整页面和组件时参考。实际样式以 `src/index.css` 和 `src/theme.css` 为准：`src/main.jsx` 先引入基础样式 `index.css`，再引入亮色主题 `theme.css`。因此 `index.css` 中仍能看到旧的深色默认值；**当前生效的是 `theme.css` 的亮色覆盖**。这份文档描述现状，不把 `docs/UI-REDESIGN.md` 中尚未实施的建议当作现有功能。

## 定位与视觉方向

- 产品是本机 OpenCode 对话的**项目优先档案浏览器**：从项目定位会话、阅读历史、按提问跳转或跨项目搜索；需要继续工作时复制恢复命令。阅读区不模拟聊天输入框。
- 视觉基调是 **Daylight archive**：白色表面、近白画布、炭灰文字、低饱和石板蓝交互强调。分区主要靠浅色边线，阴影只用于卡片悬停、提示浮层等抬升状态。
- 界面偏紧凑，阅读正文维持独立的行宽与行距；颜色应服务于层级和状态，而不是堆叠装饰。行内代码使用少量青绿色，搜索命中与加载使用暖黄色，两者都是局部例外。

## 页面层级与布局

| 区域 | 当前实现 |
| --- | --- |
| 左侧导航 `.rail` | 默认可展开的项目导航；收起宽度 `66px`，展开状态呈现项目名与快捷入口。选中项使用浅石板蓝背景及内嵌左侧强调线。 |
| 顶栏 `.workspace-bar` | 高 `48px`，白色背景与浅分隔线，负责当前位置与操作。 |
| 项目总览 `.overview` | 统计、项目网格及路径入口；项目卡片最小高度 `208px`，浅边框、低强度投影、悬停微抬升。 |
| 项目会话栏 `.session-panel` | 基础宽 `320px`（中等视口变为 `285px`），包含项目资料、会话排序、名称/工作路径筛选与可滚动会话列表；列表由服务端分页（每页 30，「加载更多」追加），每项在标题下显示首条提问预览 `.session-preview`；置顶会话整行可拖，或用 `.session-order` 上/下移按钮调整置顶组内顺序。 |
| 会话阅读 `.reader` | 白色阅读面，标题、路径、消息和「加载更早」操作；正文容器最大宽 `800px`，与工具栏、会话列表分别滚动。工具条含「查找」，打开后显示 `.find-bar`（输入、`n / 总数`、上一处/下一处、关闭），命中词以 `<mark class="find-hit">` 高亮，当前命中消息 `.is-find-active` 加深。 |
| 会话信息弹窗 `.dialog-backdrop` / `.dialog-panel` | 由会话属性栏的 `.session-info-trigger`（「编辑会话信息」）触发，经 `createPortal` 挂到 `document.body`；集中编辑标题 / 标签 / 备注。背景用 `backdrop-filter` 虚化，面板为半透明磨砂玻璃并以 `.editor-value` 悬停 chip 提供原地快速编辑；支持 Esc / 点蒙层关闭、锁定背景滚动，`prefers-reduced-motion` 下关闭动画。 |
| 提问导航 `.question-keys` | 靠右的琴键式提问索引，当前项与悬停项有石板蓝反馈，预览浮层用于浏览提问。宽度不足时正文为其预留空间。 |
| 全部记录 `.all-page` | 项目路径索引、全局搜索、范围切换（全部 / 标题与路径 / 正文）、结果列表与关键词高亮；正文命中按消息锚点展示，同一会话可有多条；搜索加载与截断状态可见。已置顶页的置顶项目整行可拖，并保留 `.reorder-buttons`（↑ / ↓）。 |

## 当前生效的根级 Token

定义于 `src/theme.css` 的 `:root`。后续样式优先引用语义变量，不要从 `src/index.css` 的旧深色 `:root` 取值。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#fafafa` | 应用画布、浅灰分区底色 |
| `--rail` | `#ffffff` | 导航与工具面板背景 |
| `--surface` | `#ffffff` | 卡片、输入框等常规表面 |
| `--hover` | `#f5f5f5` | 列表与导航的轻量悬停背景 |
| `--stroke` | `#e9e9e9` | 常规分隔线与边框 |
| `--text` | `#202020` | 主要文字 |
| `--soft` | `#525252` | 次要文字、控件文字 |
| `--dim` | `#686868` | 辅助文字、时间与路径提示 |
| `--accent` | `#405c7a` | 选中、导航图标、焦点、按钮强调（石板蓝） |
| `--accent-soft` | `#f1f5f9` | 选中/悬停的浅石板蓝底色 |
| `--code-accent` | `#087c86` | Markdown **行内代码**文字 |
| `--code-accent-soft` | `#e4f6f5` | Markdown **行内代码**背景 |
| `--sage` | `#303030` | 保留的根级变量；新样式使用前先确认实际引用 |

根节点同时指定 `color-scheme: light`、`color: var(--text)` 与 `background: var(--bg)`。目前**并非所有组件颜色都已经变量化**：例如下拉框描边 `#d8e0e8`、悬停描边 `#9cacc0`、搜索命中 `#ffe7a3`、错误反馈 `#9a3830` 都是局部值；除非需要跨组件复用，不必为它们新建 token。

## 字体、阅读与组件状态

- UI 字体栈：`"Noto Sans CJK SC", "PingFang SC", "Microsoft YaHei", -apple-system, BlinkMacSystemFont, sans-serif`。页面大标题和会话标题使用 Georgia 搭配本地中文衬线字体；路径、时间索引与代码使用 `ui-monospace, monospace`。不依赖远程字体。
- 阅读正文 `.message-body` 当前为 `14px`、`line-height: 1.78`；正文可在单词/路径中换行。Markdown 段落、列表、标题之间的间距在 `theme.css` 中收紧，代码块保留独立浅灰背景及内部滚动。行内代码由 `--code-accent*` 控制；不要把这组青绿色套到整块代码上。
- 用户消息是 `#f8f8f8` 浅灰块、左侧 `3px` 的 `--accent` 线；助手消息以底部分隔线构成阅读节奏。工具调用与思考过程采用可展开的 `.process` 面板。「仅问答」开关使用同一强调色表示开启。
- 会话选中态 `.session-item.selected` 使用 `--accent-soft` 加左侧 `--accent` 标记；普通 hover 使用近白灰。会话排序与工作路径筛选仍是**原生 `<select>`**，只自定义外观、石板蓝箭头、hover 边框和长路径省略；保留系统菜单与键盘操作。
- `button`、`input`、`select` 的 `:focus-visible` 均为 `2px solid var(--accent)`、`2px` 偏移；输入框与下拉框另有局部边框/背景反馈。提示浮层、复制成功 toast、错误状态都要同时提供文本反馈，不只靠颜色传意。

## 响应式与动效

| 宽度 | 当前行为 |
| --- | --- |
| `≤1370px` | 提问目录浮于阅读区，琴键索引靠右收进。 |
| `≤1230px` | 会话属性栏的编辑区与操作区允许重新排布。 |
| `≤920px` | 导航默认紧凑，仍可展开；项目会话栏缩窄。 |
| `≤640px` | 导航改为可展开的浮层；项目会话列表与正文逐屏切换；会话排序和筛选控件尽量保持单行，琴键缩窄，正文为琴键留出右侧空间。 |
| `≤320px` | 会话排序与筛选控件重新排成多行，防止输入框被挤压。 |

窄屏使用 `100dvh` 计算高度；弹层宽度以视口为上限，路径/长文本优先省略或局部滚动，避免整个页面横向溢出。轻微悬停、浮层和入场动画集中在 `theme.css`；`prefers-reduced-motion: reduce` 时基础样式关闭滚动动画与过渡，并减少主题中的相关动画。

## 后续修改时的落点

1. 修改全局配色或字体：先检查 `src/theme.css` 的 `:root`，再核对组件是否使用了局部硬编码颜色。
2. 修改布局或组件：先看 `src/index.css` 的基础规则，再在 `src/theme.css` 中调整**最终生效**的主题/媒体查询；需要交互状态时同时核对 `src/App.jsx`。
3. 新控件沿用白底、细描边、克制的石板蓝选中/焦点反馈；正文相关改动优先保障可读性、键盘可用性与窄屏不溢出。
4. 修改会话内查找的高亮：编辑 `src/rehypeFindHighlight.js`（unified **attacher**，必须以 `[[rehypeFindHighlight, term]]` 传入 `rehypePlugins`，不能写成 `rehypeFindHighlight(term)`），并运行 `node scripts/find-highlight-test.mjs` 验证。
